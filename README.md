# MoonlightC mods

The registry behind MoonlightC's in-app **Mod Store**. `index.json` lists every mod; each mod lives in `mods/<id>/` with a
`moonlightc-mod.json` manifest and (optionally) one JavaScript file.

To publish a mod, open a pull request that adds your folder and one entry to `index.json`.
How mods work: https://github.com/robertpierson/moonlightc/blob/main/docs/MODDING.md
